# React MySQL Login System

A full-stack Login and Registration System built using **React.js, Node.js, Express.js, and MySQL**.

## Features

* User Registration and Login
* Password Hashing using bcrypt
* MySQL Database Integration
* Responsive User Interface
* REST API

## Technologies

* **Frontend:** React.js, JavaScript, CSS, Vite
* **Backend:** Node.js, Express.js
* **Database:** MySQL
* **Tools:** VS Code, MySQL Workbench, Git, GitHub

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/skn2006-dev/react-mysql-login-system.git
   ```

2. Install dependencies in the `backend` and `my-react-app` folders:

   ```bash
   npm install
   ```

3. Configure your MySQL database and backend `.env` file.

4. Start the backend:

   ```bash
   node server.js
   ```

5. Start the frontend:

   ```bash
   npm run dev
   ```
